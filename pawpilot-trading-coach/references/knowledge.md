# On-demand trading knowledge

Explain concepts in response to the user's question: order types, execution
bounds, margin/leverage, funding, liquidation, stop-loss, fees and risk multiples.
Use the current venue/product's host-returned capabilities when applicability
matters; do not assume all venues implement the same order semantics.

Use the versioned terminal knowledge content and relevant plan/review evidence.
Distinguish a general educational example from an executable proposal and live
data. If a reference/source is unavailable, say so; do not invent a citation.

Knowledge is not consent to trade, subscribe, schedule monitoring or activate
an autonomous strategy. For a requested action, load the trading skill and
prepare a host-validated card for the user's manual review.
