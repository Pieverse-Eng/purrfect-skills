# Explain a holding

## Evidence

Use the bound position ID, native market, side, quantity, entry and fresh observed
mark, leverage/margin, protection, known costs and user-confirmed Playbook.
Paper timeline targets the owned position; Live snapshots retain each component's
freshness and source. Read only what the question needs. A missing mark does not
prevent qualitative news analysis, but it prevents describing an old PnL as current.

## Method

Explain the original stated reason for the trade, evidence supporting it now,
evidence that changed, exposure and carrying costs, and deviations from confirmed
plans. If no original reason was recorded, ask or state that it is unknown; do
not reconstruct a convincing rationale after the fact. Load market-context for
news and funding-and-costs for costs. Mention known fees even if final net is unknown.

For “should I keep holding?”, discuss which premises remain, which are challenged,
what is unresolved, and the consequences of options the user is considering.
If the user suggests another six hours, distinguish event exposure over that
period from a numerical funding illustration. Ask which assumptions they want
compared if needed. Neither blind “keep holding” nor only “decide yourself” is useful.

## Limits and counterevidence

Do not invent an opening stop or R from current protection. An entry-price stop
can still incur fees, funding, gaps and slippage; it is not guaranteed breakeven.
A current stop omission is an observation, not authority to place one. User
preferences, confirmed rules and observed behaviour remain separate. The user
chooses parameters; all supported modifications enter the original manual review.
